# David N. Serrano | Systems Analysis Portfolio

This portfolio begins with an analyst-led case study based on an honors thesis prototype using an Arduino Nano 33 IoT and Raspberry Pi Zero 2 W. The thesis describes RFID and keypad verification, serial communication, SQLite event logging, and a Tkinter administration dashboard.

The portfolio distinguishes the thesis's documented architecture and demo claims from the several Python implementation variants in the supplied Pi snapshot. It surfaces a practical systems-analysis problem: the design description, code paths, and data stores need to be reconciled before a maintainable successor can be selected.

## Project status

- **Completed:** academic/demo prototype and thesis documentation.
- **Current portfolio work:** architecture and file inventory, integration and data ownership analysis, draft requirements, and public-release safeguards.
- **Not claimed:** a production security product, a validated commercial offering, a company, or independently verified security controls.
- **Long-term interest:** investigate whether a safer and more supportable product could be developed after customer discovery and technical validation.

## What is intentionally excluded

The public package includes two short prototype recordings: one of the Raspberry Pi-connected dashboard and one showing the physical granted/denied outcomes. It does not include the thesis PDF, raw thesis screenshots, source-code variants, user registry, real card identifiers, credential values, or database files. The architecture graphic is a clean redraw based on the paper's system diagram; the recordings are demo evidence, not proof of production readiness.

## Limitations

Thesis statements about successful tests describe the author's demo and are not independent test results. The supplied Python files represent alternative implementations; they should not be described as one integrated runtime without further evidence. The product direction is an aspiration, not an existing deployment.
