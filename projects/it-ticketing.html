IT AUTOMATION / LOCAL PORTFOLIO MVP

IT Ticketing & Dashboard

A local service-desk project combining automated workflows with a read-only dashboard. Built to make ticket activity easier to inspect without replacing the existing n8n processes.

View source & setup guide ↗

Read-only ticket KPIs, status and priority charts, and recent tickets. Data reflects the development snapshot shown.

HOW IT WORKS

Automation writes. The dashboard reads.

n8n handles submissions, technician updates, Gmail notifications, and daily reporting. FastAPI queries PostgreSQL through a dedicated reader account.

Employee submissions

Forms collect requests, validate references, assign priority, and create ticket and history records before confirmation.

Technician updates

A separate workflow looks up technicians and tickets, records status changes and notes, and sends notifications.

Visibility & verification

The dashboard exposes GET-only endpoints, parameterized queries, pagination, and escaped templates. All 21 automated tests use simulated records; live features were also checked manually.

This is a local MVP without visitor authentication. Technician email lookup is not authentication. Earlier design diagrams and screenshots needing corrections are excluded from the public source.
