Systems analysis of an RFID access-control thesis prototype

01 / THE CASE STUDY

From working demo to maintainable system

The thesis describes an Arduino Nano 33 IoT handling RFID, PIN, tamper, and local feedback, with a Raspberry Pi Zero 2 W handling access decisions, SQLite logging, serial recovery, and a Tkinter dashboard. The supplied Pi folder contains alternative code paths, so the paper's design and the code snapshot are assessed separately.

01

Design vs. implementation

The thesis presents one system architecture; the Pi snapshot contains multiple alternatives that do not map cleanly to that single flow.

02 / FUTURE-STATE DIRECTION

Give each responsibility one clear home.

The recommendation is to compare a local-first design with a service-and-dashboard design, then select one serial owner and one authoritative user/event store based on administrator needs, failure behavior, and deployment constraints.

LONG-TERM DIRECTION

Build a product responsibly, starting with evidence.

The long-term ambition is to explore whether this idea can become a real access-control product. The present work is an academic prototype, not a company, validated product, or production-ready system. Any next version needs customer discovery, threat modeling, privacy and safety requirements, operational failure policies, and controlled validation before real-world use.
