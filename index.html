01 / HONORS THESIS PROJECT

RFID-Based Multi-Factor Access Control System

Designed and demonstrated as an honors-thesis project, the prototype combines RFID and keypad input with Arduino hardware, a Raspberry Pi decision and logging layer, and an administrator dashboard. The thesis describes the target architecture; the supplied Pi folder contains several software alternatives, so this case study separates what I demonstrated from what the files show.

04 / NEXT STEPS FOR THE THESIS

Clarify the prototype before choosing its next version.

The thesis proposes an RFID-and-keypad access flow: Arduino handles credential input and local feedback, while the Raspberry Pi makes access decisions, records events, and supports an administrator dashboard. The supplied Pi folder contains several alternative implementations, not one confirmed integrated runtime. Next steps are to confirm the intended demo workflow, choose one serial-port owner and one user/event data store, then validate failure and security requirements with synthetic data before considering any real-world pilot.
