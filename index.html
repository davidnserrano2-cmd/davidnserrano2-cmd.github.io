01 / HONORS THESIS PROJECT

RFID-Based Multi-Factor Access Control System

Designed and demonstrated as an honors-thesis project, the prototype combines RFID and keypad input with Arduino hardware, a Raspberry Pi decision and logging layer, and an administrator dashboard. The thesis describes the target architecture; the supplied Pi folder contains several software alternatives, so this case study separates what I demonstrated from what the files show.

THESIS DESIGN / SYSTEM PREVIEW

Hardware at the edge. Local control on the Pi.

The thesis places the Arduino between reader/keypad inputs and the Pi backend. The Pi evaluates access, logs events, and supports an administrator dashboard; outcomes return to the Arduino for physical feedback.

A thesis-based redraw that distinguishes the device feedback path from the dashboard monitoring path.

02 / NEXT-STAGE DESIGN

Give each responsibility one clear home.

The code review identifies two deployment patterns: a local-first application and a Pi service with a separate dashboard. A consolidated design needs one serial owner, one authoritative user and event store, and a documented failure policy.
